# shixiong-econ_paper_viz

**经管大师兄 · 经济学论文可视化精读集**
Deep-read HTML editions of top economics papers, by [ShiXiongEcon](https://github.com/ShiXiongEcon).

每一份精读为一个独立 HTML 文件，风格统一（长报道式排版、内嵌 MathJax 公式）；文件按 **序号-作者-发表时间-期刊-题目** 命名，便于检索。

## 使用方式

- **在线阅读**：直接点上方「阅读」链接（GitHub Pages 托管）。
- **本地阅读**：克隆本仓库后用浏览器打开对应 HTML 文件。

## 命名规范

```
<序号>-<第一作者>-<发表年>-<期刊>-<题目下划线连接>.html
```

例：`01-Chen-2026-Econometrica-Economic_Growth_and_the_Rise_of_Large_Firms.html`
